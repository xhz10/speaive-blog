# 管理员访客统计

后台入口：`/studio/analytics/`，也可以点击写作台导航中的“访客”。只有 ADMIN 可以读取页面和 API；会员角色不具备读取权限。

## 记录什么

| 字段 | 来源与含义 |
| --- | --- |
| 访问时间 | 后端接收时间；数据库保存 UTC，后台按北京时间显示 |
| 文章 | 当时的稳定 ID、slug 和标题快照；归档不删除已有访问记录 |
| IP | 原始连接或受信任 Astro 代理提供的地址；不会读取请求体里的 IP |
| 地点 | 离线 IP 数据库的粗略归属地，不调用定位权限或 GPS |
| 设备类别 | 手机、平板、电脑、机器人、未识别 |
| 设备型号 | 浏览器允许时使用 UA Client Hints 的 model，否则尝试旧 UA 中的 Android 型号；没有就显示“未提供型号” |
| 操作系统 / 浏览器 | 请求用户代理的尽力识别结果，不是可靠身份证明 |
| 来源 | 来源网站主机名；不保存来源完整 URL、查询参数或表单信息 |

UA Client Hints 由浏览器决定提供哪些信息，不能承诺每台设备都有具体型号。移动浏览器可提供 model，空字符串表示不适用或未知；iPhone 通常只能识别手机和系统，不能可靠地区分具体代际。[UA Client Hints 规范](https://wicg.github.io/ua-client-hints/)。不做 Canvas、字体列表或其他额外设备指纹采集。

## 统计口径

- 页面实际进入可见状态时上报一次；刷新或再次打开是新的访问，返回后台不会把同一事件重新计数。
- 页面为事件分配 UUID，服务端按事件 ID 幂等插入。脚本被阻止、JavaScript 关闭、离线或提交失败的访问可能漏记。
- 访问次数是 PV；估算访客以 `SHA-256(IP + 用户代理)` 去重。共享出口可能合并访客、动态 IP 可能拆分同一访客，所以它不是自然人数。
- 默认排除已登录管理员，以及 UA 中能识别的机器人。未声明身份的爬虫仍可能混入。
- 不要求注册，也不创建永久访客 ID。匿名上报沿用现有 CSRF cookie；没有为统计新增持久身份 cookie。
- 时间范围支持今天、近 7/30/90 天；范围按北京时间自然日计算，并受保留期限限制。筛选文章后计数、排行和明细保持同一口径。
- 明细默认保留 90 天，定时入口每小时清理最多 10000 条过期记录。极高积压时会分多轮清理；默认没有永久历史汇总表。

## 安装离线地点库

在项目根目录执行：

```sh
./scripts/setup-geoip.sh
```

脚本读取 `.env` 中的目录设置，默认写入 `.data/geoip/ip2region_v4.xdb` 和 `ip2region_v6.xdb`，约 47 MB。它下载固定提交版本并校验 SHA-256，下载失败不覆盖已有文件。文件不进入 Git。应用启动时加载内存，更新库后重启后端。

数据与 Java 适配器来自 [ip2region 官方项目](https://github.com/lionsoul2014/ip2region)，查询过程在本地完成；Java 服务使用其并发安全查询接口。[Java 使用说明](https://github.com/lionsoul2014/ip2region/blob/master/binding/java/README.md)。当前脚本固定数据提交 `c1a1fc7d5941760db3f8431dc05c48cf7f0e30a1`；维护时一起更新版本与校验值，保留上游项目及数据来源说明。

没有安装数据库也可以启动并记录访问，公网地点显示“未知”，回环或内网地址显示“本地 / 内网”。配置了损坏或不兼容的文件时启动会失败，避免默默使用错误数据库。IPv4、IPv6 库可以独立存在，缺少某一库时该协议的地点显示未知。

## 配置与代理

| 环境变量 | 默认值 | 含义 |
| --- | --- | --- |
| `SPEAIVE_ANALYTICS_ENABLED` | `true` | 是否采集新访问，关闭不会删除旧数据 |
| `SPEAIVE_ANALYTICS_RETENTION_DAYS` | `90` | 明细保留期限，1–3650 天；界面单次最多查 90 天 |
| `SPEAIVE_ANALYTICS_GEO_DIRECTORY` | 数据目录下 `geoip` | 裸机运行时地点库目录 |
| `SPEAIVE_ANALYTICS_TRUST_PROXY_HEADERS` | `false` | 后端是否允许从指定代理读取来源 IP |
| `SPEAIVE_ANALYTICS_TRUSTED_PROXIES` | 回环与常见私有网段 | 允许传递 IP 的连接来源 CIDR 列表，可缩窄到实际代理网段 |
| `SPEAIVE_TRUST_PROXY_HEADERS` | 前端裸机默认关闭 | Astro 是否信任最外层主机代理的来源头 |

Compose 已将后端留在内部网络、开启后端代理信任，并把 `/data/geoip` 映射到数据目录。面对公网的反向代理须覆盖客户端提交的 `X-Real-IP` / `X-Forwarded-For`，不能透传伪造头。Astro 再规范为单个 IP。裸机部署如果浏览器先访问 Astro，应在确认后端仅供可信代理访问后开启后端信任选项；否则记录的是 Astro 的连接地址。

现有 Spring 配置会包装请求的 remoteAddr，所以统计入口先展开请求包装取原始连接，再检查代理网段。不能拿已经被转发头改写的地址来验证“是不是可信代理”。

模型生成请求可能持续较久，部署网关的超时应结合角色数量和供应商延迟调整；访客采集是短请求，不依赖 AI。

## API 与数据安全边界

- `POST /api/v1/public/posts/{slug}/visits`：匿名可调用，必须携带 CSRF；返回 204，不返回 IP 或任何明细。私密、未发布或不存在的文章不能记录。
- `GET /api/v1/studio/analytics?days=7&page=1&pageSize=25&postId=...`：仅 ADMIN。默认每页 25，最大 100，响应不缓存。
- 同来源 IP 每分钟最多提交 120 次；跟踪限流地址上限 10000，防止限流器自身无限增长。多实例部署时此限制按进程生效。
- 迁移 [V10](../speaive-blog-infrastructure/src/main/resources/db/migration/V10__article_visit_analytics.sql) 新建访问表及时间、文章索引，不修改已有迁移。

## 本地验收

打开一篇已公开文章，再以管理员查看“访客”；若当前浏览器已经登录管理员，请使用另一个浏览器或无痕窗口产生一次匿名访问。同一个事件重发不应增加 PV，普通会员请求统计应返回 403，匿名读取应返回 401。更新文章标题或归档不改写历史访问的标题快照。
