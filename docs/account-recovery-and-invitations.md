# 会员密码找回、改密与邀请码管理

本轮面向受邀会员，不改变站长环境配置中的密码。目标是朋友忘记密码时能恢复访问，站长误发邀请码时能立即停止继续注册。公开文章的加载容错见 [阅读页容错](reading-resilience.md)。

## 使用流程

### 已登录会员改密码

在“我的写作 → 账号与存储”输入当前密码、新密码和重复确认。服务端验证当前密码及登录时的凭证版本，再保存新密码哈希。成功后重新登录；其他旧登录在下一次请求时失效，打开的编辑窗口不会被前端主动清空。

密码保留现有 10 到 100 个字符规则，另要求 UTF-8 编码不超过 72 字节，避免 BCrypt 对较长中文密码或表情抛出服务端异常。注册、改密和找回使用一致的校验；密码本身不会被自动去掉首尾空格。

### 忘记密码，由站长协助

1. 会员联系站长并说明自己的用户名。站长先通过已有联系渠道确认对方身份。
2. 站长在会员管理中生成一次性链接，确认用户名和到期时间，再自行交给该朋友。生成链接不会立即修改密码，也不会立即退出对方账号。
3. 链接有效 30 分钟。新链接替代该账号之前的链接，原始令牌只在签发结果中展示一次。
4. 朋友打开链接，自己输入两次新密码。使用成功后链接立即失效，旧密码与旧登录失效，需要重新登录。

当前没有邮件系统，不提供假装已经发送邮件的“找回成功”提示。前端通过 URL 的 `#token=...` 片段携带令牌，加载后立即从地址栏移除，只在当前页面内存中保留。刷新或关闭后需要重新打开原链接；不能从 query 参数接受令牌。

## 安全与数据边界

- 数据库只保存随机令牌的 SHA-256 哈希；原始令牌为至少 256 位随机值，不写入日志、HTML 序列化或浏览器持久存储。找回页面禁止缓存和索引，不发送 Referer。
- 账号行锁先于令牌行锁；拿到锁后才检查到期时间，校验、密码写入、令牌消费及旧令牌撤销处于同一事务。并发提交同一链接最多一个成功。
- 独立的 `credential_version` 只表示密码凭证版本，不能复用写作设置版本。改密与资格/加密设置并发时不能互相覆盖。
- 每次会员请求验证认证时的凭证版本，确保旧会话在 Agent、写作和设置等入口统一失效。匿名消费链接仍要求 CSRF，改密与找回分别限流。
- 改密码不修改内容密钥，不解密或重写文章，不改变加密开关、作者资格或公开范围。数据库中的加密正文及历史版本继续使用现有存储设置。

## 邀请码管理

生成时可以填写 200 字以内的管理备注，例如“给某位朋友”。原始邀请码仍只在生成成功后显示一次；列表提供状态、备注、使用次数与到期时间。

撤销只阻止以后使用该邀请码注册，不停用已经注册的会员。注册与撤销锁定同一条邀请记录：先完成注册则保留已注册账号，先完成撤销则后续注册拒绝。重复撤销保持原撤销时间，属于幂等操作。过期、用完、撤销分别显示，不能都叫“失效”。

## 接口与代码入口

所有写接口继续使用 `{code,message}` 错误响应并要求 CSRF。

| 接口（省略 `/api/v1`） | 权限 | 行为 |
| --- | --- | --- |
| `POST /account/password/change` | 已登录会员 | 当前密码、新密码及 `X-Writing-Username`；成功后重新登录 |
| `POST /studio/members/{username}/password-reset` | 站长 | 签发一次性令牌，返回用户名、令牌、到期时间 |
| `POST /account/password/reset` | 可匿名 | 消费令牌并设置新密码；不自动登录 |
| `POST /studio/invitations` | 站长 | 原有有效天数/使用次数，追加可选备注 |
| `POST /studio/invitations/{id}/revoke` | 站长 | 幂等撤销，返回更新后的邀请信息 |

`domain/account` 维护账号凭证版本、邀请撤销规则及一次性令牌有效性；application 的密码管理用例编排事务与端口；infrastructure 存储哈希和并发条件；start 的安全适配层处理密码校验、BCrypt、Session、CSRF 和限流。Flyway 新增 V13，旧迁移不修改。

升级后，缺少凭证版本的历史会员登录需要重新登录。站长登录继续采用环境配置中的密码。
