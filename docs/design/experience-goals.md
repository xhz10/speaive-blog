# 读者与作者体验优化目标

目标：受邀的朋友知道如何开始写、能找回自己的文字，读者能找到他们主动公开的作品。延续当前的阅读视觉，不靠增加装饰判断改进是否有效。

| 优先级 | 体验问题 | 完成标准 |
| --- | --- | --- |
| P0 | 写作时登录过期可能被带离编辑器 | 保留输入，提示在新窗口登录，同一账号恢复后能继续；版本冲突不得覆盖远端 |
| P0 | 归档后只能去数据库找历史 | 作者能查看自己的归档并恢复；恢复为仅自己可见的草稿，历史与加密保留 |
| P1 | 朋友的公开文章只有直达链接 | 提供“朋友的文字”入口与分页列表，可进入作者主页；不展示私密、归档或停用账号内容 |
| P1 | 文章积累后难以找到草稿 | 我的文章提供全部、仅自己可见、已公开、归档筛选，分页与计数一致 |
| P1 | 受邀注册后不知道下一步 | 解释用户名规则、主页地址、作者/发布权限、存储设置；保留登录与注册的返回目标 |

## 验证原则

- 使用独立本地数据库和演示账号，不操作线上数据。
- 权限与过滤必须在后端落实，先限定可访问行再解密，不以 CSS 隐藏代替安全边界。
- 归档恢复复用 Post 聚合，保持所有者、修订历史、乐观锁和事务语义；恢复不自动公开。
- 不把未保存文本存入浏览器明文缓存，不自动更新已经公开的正文。
- 完成后执行真实 PostgreSQL 集成测试、领域和架构测试、前端检查与浏览器手机/桌面验收。

## 后续候选

自动保存需要处理跨标签并发、登录过期、公开稿与草稿分离，以及历史数量控制，应独立设计。搜索加密正文不能建立泄露内容的明文索引。当前优先完成上述五项可验证目标。

## 完成记录（2026-09-12）

五项目标已实现。主导航增加“朋友”；首页展示最近公开的朋友作品；`/community/` 提供分页阅读与作者主页链接。`/writing/` 的筛选由后端分页执行，归档列表可以找回文章；找回保留原文和历史，自动回到私密草稿。

写作时会话过期不会跳走；页面提供新窗口登录与查看已保存版本的入口。重新登录后原页面可继续保存；不同账号会被拦截，版本冲突不会自动重试覆盖。注册提供用户名规则、即时主页路径、密码显示切换，并保留有效的返回位置。新会员会看到注册、作者资格、发布资格各自的状态。

### 验收证据

- 后端执行完整 `./mvnw clean verify`，139 项测试全部通过，包含真实 PostgreSQL、领域、应用、HTTP、ArchUnit 与打包运行测试。
- 归档测试覆盖他人访问、旧版本、CSRF、加密后恢复、重复归档、多次恢复、两个并发恢复请求，以及历史写入失败时活动行回滚。
- 公开作品测试覆盖跨页计数、停用账号、归档移除、私密损坏密文不被读取；所有分页过滤都在解密之前执行。
- 前端执行 `pnpm test` 与 `pnpm run build:frontend`；63 项测试全部通过，类型检查无错误、警告或提示；新增会话恢复、版本冲突、账号切换、返回路径安全的测试。
- 浏览器实测从导航发现作品、作者登录、私密筛选、归档找回、注册用户名路径预览、密码显示切换、普通会员引导。
- 使用两个窗口实测：原窗口保留未保存文字 → 另一窗口退出登录 → 原窗口保存提示过期但不跳转 → 同一账号重新登录 → 原窗口保存成功。再切换到其他账号时，旧编辑器拒绝提交。
- 桌面及手机宽度下检查页面，手机内容宽度与滚动宽度一致。测试仅使用独立本地数据库和演示账号，未部署线上。

### 使用入口

- 读朋友作品：`/community/`
- 找自己的草稿：`/writing/?filter=PRIVATE`
- 找回归档：`/writing/?filter=ARCHIVED`
- 查看权限和存储：`/writing/settings/`
- 站长开通作者资格：`/studio/members/`
