# 写作台编辑器与标签

## 业务目标

写作台面向一个长期维护个人博客的管理员。编辑体验需要比普通多行文本框更适合长文，同时继续保存可迁移、可导出的 Markdown，而不是把正文锁进某一种富文本格式。

标签的目标也不是给文章增加一行装饰文字，而是建立文章之间的横向入口：读者从首页、归档或文章正文点进标签后，可以看到同类公开文章和对应数量。标签不参与文章权限判断，“公开 / 仅管理员”仍是独立的可见性设置。

## Markdown 编辑器

正文区使用 CodeMirror 6 的 Markdown 模式，提供：

- Markdown 语法高亮、行号、当前行提示和自动换行；
- 撤销、重做、搜索，以及 Tab 缩进；
- 标题、加粗、斜体、链接、列表、引用和代码的快捷按钮；
- `Cmd/Ctrl + B` 加粗、`Cmd/Ctrl + I` 斜体、`Cmd/Ctrl + F` 搜索；
- 字符数和行数统计；
- 后端 Markdown 实时预览；
- 原有的自动保存、本地草稿恢复、图片上传和粘贴图片能力。

编辑器仍把纯 Markdown 写入原有 `body` 字段，后端接口、数据库模型、导入导出格式和部署脚本都没有因此改变。CodeMirror 只在新建和编辑文章的页面加载，不影响公开页面的阅读脚本。

## 标签输入与使用

在写作台输入一个标签后按回车，它会立即变成标签块：

- 点击标签块右侧的 `×` 可以删除；
- 输入框为空时按退格，会删除最后一个标签；
- 逗号、中文逗号和顿号也可以作为兼容分隔符；
- 标签会去掉首尾空格，并进行不区分大小写的去重；
- 每篇文章最多 20 个标签，单个标签最多 40 个字符。

公开文章的标签会出现在文章列表和正文页，链接到 `/archive/?tag=标签名`。归档页会汇总所有公开文章的标签和数量，并按所选标签筛选；仅管理员文章不会进入公开标签计数。

个人博客不需要为每篇文章堆很多标签。建议优先维护少量、稳定、会重复使用的主题词，例如“写作”“读书”“技术”，通常每篇 1 到 3 个就足够。只出现一次且今后也不会继续使用的词，对导航价值很小，可以不加。

## 验收

代码检查与自动化测试：

```bash
pnpm check
pnpm test
pnpm build:frontend
```

页面验收至少覆盖桌面端和移动端，并检查正文录入、格式按钮、预览、标签新增与删除、草稿自动保存，以及从公开文章标签进入归档筛选。
